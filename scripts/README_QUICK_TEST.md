# Быстрый тест FundingTracker - 3 Сценария Симуляции

## Зачем это нужно?

Вместо того чтобы ждать **час** до следующего фандинга и подключаться к реальным биржам, этот скрипт:

- ✅ Симулирует 3 ключевых сценария за **~1 минуту**
- ✅ Использует **mock данные** (не нужны реальные биржи)
- ✅ Полностью **безопасно** (никаких API вызовов)
- ✅ Показывает **все 3 случая работы** FundingTracker v3.0

## Что делает скрипт?

Запускает **3 независимых сценария** подряд, каждый по 15 секунд:

### Сценарий 1: ✅ ВСЕ ОКЕЙ - Положительный spread

```
Exchange1 (SHORT): rate = +2.0 bps
Exchange2 (LONG):  rate = +1.0 bps
Spread = 2.0 - 1.0 = +1.0 bps (положительный!)

✅ Ожидание: Позиция остается ОТКРЫТОЙ
```

### Сценарий 2: ⚠️ Smart PnL Close - Spread < -3 bps (< -0.03%)

```
Exchange1 (SHORT): rate = +1.0 bps
Exchange2 (LONG):  rate = +5.0 bps
Spread = 1.0 - 5.0 = -4.0 bps (отрицательный!)

⚠️  Ожидание: Позиция ЗАКРЫВАЕТСЯ через Smart PnL Close
```

### Сценарий 3: 🚨 Market Close - Spread < -20 bps (< -0.2%)

```
Exchange1 (SHORT): rate = +1.0 bps
Exchange2 (LONG):  rate = +25.0 bps
Spread = 1.0 - 25.0 = -24.0 bps (КРИТИЧЕСКИЙ!)

🚨 Ожидание: Позиция ЗАКРЫВАЕТСЯ СРОЧНО через Market Close
```

## Использование

### Запустить все 3 сценария

```bash
python3 scripts/test_funding_monitor_single_pair.py
```

✅ **Расчет funding spread** - правильная формула (rate_ex1 - rate_ex2)  
✅ **Положительный spread** - позиция НЕ закрывается  
✅ **Порог Smart PnL Close** (-3 bps) - позиция закрывается нормально  
✅ **Порог Market Close** (-20 bps) - позиция закрывается срочно

## Важные замечания

⚠️ **Скрипт НЕ использует реальные биржи!**  
Все данные симулированы - funding rates, balances, orderbooks.

✅ **Полностью безопасно**  
Никаких сетевых запросов, никаких API вызовов.

✅ **Проверяет логику, а не API**  
Фокус на правильности алгоритма FundingTracker, а не на работе с биржами.

## Troubleshooting

### Позиция не закрывается в сценарии 2 или 3

**Причина:** Возможно, не включен `funding_monitoring_enabled`

**Решение:** Проверьте в функции `create_test_position()`:
```python
funding_monitoring_enabled=True  # Должно быть True!
```

### Тест не запускается

**Причина:** Синтаксическая ошибка или missing imports

**Решение:**
```bash
python3 -m py_compile scripts/test_funding_monitor_single_pair.py
```

### Тест зависает

**Причина:** FundingTracker не останавливается

**Решение:** Нажмите `Ctrl+C` для экстренной остановки
